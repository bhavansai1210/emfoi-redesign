# EMFOI Premium Refinement Plan

This plan outlines the highest-impact improvements to elevate the EMFOI redesign into a polished, enterprise-grade experience.

## 1. Visual & UX Refinements
- [ ] **Mobile Header Optimization**: Rework the homepage mobile header to be more compact. The "Request a briefing" and "Download" buttons should not dominate the first fold.
- [ ] **Interactive States**: Enhance hover and focus states for all cards (Capabilities, Industries, Products) with subtle depth and motion.
- [ ] **Section Pacing**: Improve whitespace and vertical rhythm across all routes to ensure a "premium" airy feel.
- [ ] **Leadership Integration**: Refine the About page leadership section to feel more integrated and authoritative.
- [ ] **Typography Audit**: Ensure consistent font-weight usage and hierarchy across all components.

## 2. SEO & Technical Excellence
- [ ] **Sitemap & Robots**: Verify `sitemap.xml` and `robots.txt` are correctly generated and served.
- [ ] **Metadata Optimization**: Ensure all routes have unique, keyword-rich titles and descriptions aligned with the Part A brief.
- [ ] **Performance Pass**: Optimize image loading (eager vs lazy) and minimize layout shifts.
- [ ] **Accessibility Audit**: Verify ARIA labels, focus management, and color contrast.

## 3. Content Quality
- [ ] **Part A Verification**: Ensure every requirement from the "Website and Presence Instructions" is met exactly.
- [ ] **Copy Polish**: Review all copy for "Civic Precision" tone consistency (authoritative, precise, warm).

## 4. Interaction Design
- [ ] **Scroll Reveal Enhancements**: Refine Framer Motion scroll reveals to be smoother and less distracting.
- [ ] **Micro-interactions**: Add subtle confirmation animations for form submission and button clicks.
